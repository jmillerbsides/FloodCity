You just scanned a code without checking where it went.

Nothing bad happened here. This page is the last slide of my talk, No Exploit Required. Attackers love QR codes because you can’t read where they lead until after you scan them, and that same trick shows up in device code phishing lures.

Next time

  1. Read the link before you open it.Your phone’s camera shows the address first. Check it, don’t just tap.
  2. Be wary of codes that ask you to sign in.A QR code that jumps straight to a login page deserves a second look, even if it arrived from someone you know.
  3. Only enter a code on a Microsoft sign-in page if your own device just showed it to you.If someone else sent you the code, don’t.
  4. Never paste a command because a web page told you to.No real site or help desk will ask you to.
